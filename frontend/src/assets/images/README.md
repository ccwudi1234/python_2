# 图片资源说明

本项目使用的图片资源均来自免费可商用的网站：

## 推荐资源网站

1. **Flaticon** - https://www.flaticon.com/
   - 用于获取 Logo 和图标
   - 建议搜索："code", "programming", "computer" 等关键词

2. **Unsplash** - https://unsplash.com/
   - 用于获取首页背景图
   - 建议搜索："minimal code", "programming dark", "coding" 等关键词

3. **Element Plus Icons** - 内置图标库
   - 项目中已包含，无需额外下载
   - 可用图标：Document, Monitor, Grid, Upload, User 等

## 图片放置位置

```
assets/images/
├── logo.svg              # 网站 Logo
├── hero-bg.jpg          # 首页背景图
├── avatar.png           # 默认用户头像
└── placeholder.png      # 占位图（可选）
```

## 使用说明

由于无法直接下载图片，您可以：
1. 访问上述网站下载适合的图片
2. 或者直接使用 Element Plus 的图标替代
3. 也可以使用我们提供的 CSS 渐变背景作为替代方案
